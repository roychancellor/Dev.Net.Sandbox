On AZ01ISDS, in a command window, go to W:\Roy Chancellor\dev.ssl

MAKE A PUBLIC KEY FROM A PRIVATE KEY:
openssl rsa -in "W:\Roy Chancellor\dev.ssl\<<name of private key.pem>>>" -outform PEM -pubout -out "W:\Roy Chancellor\dev.ssl\key.public_pkcs8.pem"

TO MAKE IT IN PKCS1 FORMAT (ENDS UP BEING THE SAME AS ABOVE)
openssl rsa -in "W:\Roy Chancellor\dev.ssl\key2048_sqa.private_open_pkcs8.pem" -outform PEM -pubout -traditional -out "W:\Roy Chancellor\dev.ssl\key.public_pkcs1.pem"

IF THE PRIVATE KEY HAS A PASS PHRASE:
openssl rsa -in "W:\Roy Chancellor\dev.ssl\key2048_sqa.private.pem" -passin file:"W:\Roy Chancellor\dev.ssl\passphrase.txt" -outform PEM -pubout -out "W:\Roy Chancellor\dev.ssl\key.public.privatehadpassword.pem"

TO CONVERT PRIVATE KEY TO PKCS8 FORMAT:
openssl pkcs8 -topk8 -inform PEM -outform PEM -nocrypt -in "W:\Roy Chancellor\dev.ssl\key2048_sqa.private_open.pem" -out "W:\Roy Chancellor\dev.ssl\key2048_sqa.private_open_pkcs8.pem"
